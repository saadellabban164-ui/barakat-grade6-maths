# Grade 6 Maths — Barakat Private Language School

The final product is an English-first Grade 6 Maths quiz platform for language classes 6A and 6B at Barakat Private Language School. The visual direction follows a calm, clear educational dashboard: deep navy for trust, teal for progress, warm gold for recognition, generous cards, short actions, and responsive mobile behavior.

The homepage introduces Grade 6 Maths, lets a student save a real name and class, starts the practice quiz, and shows a separate leaderboard for 6A and 6B. The quiz has 20 questions, a 20-minute timer, immediate feedback, and a saved result. The admin portal accepts only Firebase Authentication; there is no hard-coded demo password. Firebase configuration and Firestore Rules are documented separately.

The final build deliberately contains no fabricated student names, scores, teacher claims beyond the requested Ms. Shaimaa Saad identity, or fake Firebase credentials. Empty states explain when no real results or quizzes have been recorded.
